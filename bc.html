2020

export-layers

Inkscape 1.0 extension

Exports each layer of an Inkscape drawing as its own SVG, PNG, JPEG or PDF file. It is a port of an older extension to Inkscape 1.0.

2020

multilayer-grid

Inkscape 1.0 extension

Arranges the selected objects into a grid. When a grid fills, the rest continue on a new layer.

2022

esp32cam-gdrive

ESP32-CAM sketch + Google Apps Script

An ESP32-CAM takes a photo on a timer and uploads it to a Google Drive folder through an Apps Script web app. WiFi is set up from a phone through a captive portal.

2022

villager-essentials

Spigot 1.19 plugin (Java)

Changes villager trading for multiplayer Minecraft servers: discounts one player earns apply to everyone, villagers killed by zombies always convert, and zombies pick up items.
