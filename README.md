# Kyle Hunady - Personal Website

A clean and simple GitHub Pages portfolio for a graduate student. This site showcases education, projects, research, and provides contact information.

## 📁 Project Structure

```
├── index.html           # Home page with hero section
├── about.html           # About, education, and skills
├── projects.html        # Projects and publications
├── assets/
│   └── css/
│       └── style.css    # All styling
└── README.md            # This file
```

## 🚀 Pages

- **Home** (`index.html`) - Welcome section with quick navigation
- **About** (`about.html`) - Background, education, skills, and interests
- **Projects** (`projects.html`) - Research projects and publications

## 📝 Getting Started

1. **Customize Content**: Edit the HTML files to add your own:
   - Update your name, email, and social links in the hero section
   - Add your education history and skills on the About page
   - List your projects and publications on the Projects page

2. **Update Contact Information**: Replace placeholder links:
   - Email address
   - GitHub profile URL
   - LinkedIn profile URL

3. **Deploy to GitHub Pages**:
   - Push your changes to GitHub
   - Go to repository settings → Pages
   - Ensure it's set to deploy from the main branch
   - Your site will be live at `https://kylehunady.github.io`

## 🎨 Customization

### Add New Sections
Edit the HTML files to add more content sections. The site uses a responsive grid layout that works on all devices.

### Change Colors
Modify the CSS variables in `assets/css/style.css`:
```css
:root {
    --primary-color: #2c3e50;
    --secondary-color: #3498db;
    --accent-color: #e74c3c;
    /* ... other colors ... */
}
```

### Add Images
Create an `assets/images/` directory and reference images in your HTML files.
