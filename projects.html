Monte Carlo Mössbauer Ray-Tracer Python · Plotly →

Designing a miniaturized Mössbauer spectrometer for Mars means making hard tradeoffs between photon count rate and spectral fidelity — more signal often means accepting geometric distortion. I built a Monte Carlo photon ray-tracer to model these tradeoffs across different source, sample, and detector arrangements. The simulator characterizes spectral distortion through a smearing kernel that can correct fits on real hardware. Output includes interactive 3D Plotly visualizations of photon trajectories.

ESP32 Subway Tracker C++ · ESP32 · Hardware

Subway arrival displays typically run on a Raspberry Pi (~$40) parsing transit protocol data. I got it working on an ESP32 ($5) with a 2" OLED display ($5). A $10 desktop widget that does the same job. Code on GitHub.

Coffee Cropper Python · OpenCV →

The latte art photos on this site don't crop themselves. Coffee Cropper uses bilateral filtering and Hough circle detection to find the coffee surface in a photo and batch-export the results. The hardest part: distinguishing the cup rim from the plate beneath it. Built specifically for this site.
